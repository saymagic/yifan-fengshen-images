# 一饭封神 · 菜品封面

小程序使用的独立图片仓库。图片按参赛记录 ID 管理，同名菜的不同作品保持独立。

- `covers/v1/`：已通过视觉复核的 JPEG 封面。
- `manifest.json`：图片类型、来源依据、尺寸、哈希及审核说明。
- `catalogue.json`：全部 330 条参赛记录；`approved` 为菜品示意图，`placeholder` 为成品待核实的中性封面。
- `prompts/`：最终生成提示词。
- `STYLE.md`：统一摄影风格与更新约定。

2026-10-03 已覆盖两季全部 330 条参赛记录：328 张菜品 AI 示意图、2 张待核实中性封面。每张图片分别保留提示词、依据与目视复核意见。AI 图片根据菜名、已知组成或节目可见形态生成，仅供示意，并非节目原始照片；图片不会证明完整节目配方已经公开。

S1-D041「一饭」与 S1-D120「游戏人间」尚缺可靠成品依据，使用闭合器皿占位。展示时必须使用 `成品待核实` 标签及清单中的说明，不能视为该菜的外观还原。

原始文件可通过 GitHub Raw 访问。小程序使用现有 HTTPS 服务提供这些文件的校验副本；应用清单固定 Git 提交与 SHA-256，确保展示内容可以追溯到本仓库。
