# 一饭封神 · 菜品封面

小程序使用的独立图片仓库。图片按参赛记录 ID 管理，同名菜的不同作品保持独立。

- `covers/v1/`：已通过视觉复核的 JPEG 封面。
- `manifest.json`：图片类型、来源依据、尺寸、哈希及审核说明。
- `catalogue.json`：全部菜品及其图片处理进度，pending 不能视作已完成。
- `prompts/`：最终生成提示词。
- `STYLE.md`：统一摄影风格与更新约定。

当前为持续整理中的图库。AI 图片根据菜名与已知组成生成，仅供示意，并非节目原始照片；图片不会证明完整节目配方已经公开。

原始文件可通过 GitHub Raw 访问。小程序使用现有 HTTPS 服务提供这些文件的校验副本；应用清单固定 Git 提交与 SHA-256，确保展示内容可以追溯到本仓库。
